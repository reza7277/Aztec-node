### Aztec Node Sequencer Steps

Prepare RPC and Faucet for Aztec Node

Before running the Aztec node, make sure you have access to the Ethereum Sepolia RPC, Sepolia Beacon RPC, and testnet funds from the Ethereum Sepolia Faucet.

* **Ethereum Sepolia RPC**: Use providers like Alchemy, Infura, or public Sepolia nodes. Example endpoint: `https://sepolia.infura.io/v3/YOUR_API_KEY` (replace YOUR\_API\_KEY with your API key).
* **Sepolia Beacon RPC**: Use the Beacon Chain endpoint for Sepolia, such as from a node service provider. Example: `https://drpc.org/chainlist/eth-beacon-chain#eth-beacon-chain-sepolia`.
* **Ethereum Sepolia Faucet**: Get testnet ETH for Sepolia from an official faucet, such as:

  * Google Cloud Sepolia Faucet
  * Make sure you have a wallet that supports Sepolia to receive testnet funds.

### Run the Aztec Node

Run the Aztec node on your server using the following one-click script:

```
wget -q https://raw.githubusercontent.com/reza7277/Aztec-node/refs/heads/main/Aztec.sh && chmod +x Aztec.sh && ./Aztec.sh
```

Make sure you have configured the node with the prepared Ethereum Sepolia RPC and Sepolia Beacon RPC.

After the node is running, wait about 15 minutes for the node to synchronize and be ready for use.

### Check Block Number and Proof

After the node has finished syncing, check the block number and proof needed for the verification process.
Open the Aztec node installation menu (usually available in the terminal or node interface after running the script).
Look for the option or command in the installation menu to display the block number (the latest block number from your node) and proof (the data proof generated by the node).
Carefully note this information, as it will be required by the Discord bot later.

### Join the Aztec Discord Server

Join the Aztec Discord Server through the following link: [Aztec Discord](#).
After obtaining the block number and proof, enter the Aztec Discord server and navigate to the `operators | start-here` channel.

### Use the Command to Start

In the start-here channel, type the following command to start the process of obtaining the Apprentice role:

```
/operator start
```

After running the command, the bot will ask for some information.

### Provide the Required Data

The bot will request several pieces of information, such as:

* **Address**: Your wallet address used on the Sepolia network.
* **Block Number**: The block number from your Aztec node, which you have noted.
* **Proof**: The proof or data required, which you obtained from the installation menu.

Enter each piece of data one by one as requested by the bot.

### Get the Apprentice Role

Once all the information is entered correctly, you will immediately receive the Apprentice role in the Aztec Discord server.

### Tips

* Make sure your node is running and properly connected to the Ethereum Sepolia RPC and Sepolia Beacon RPC before attempting to get the role.
* Double-check the block number and proof in the installation menu to ensure the data you enter into the Discord bot is accurate.
* Don't worry if the bot doesn't respond immediately, this is normal during the synchronization process.
* Ensure you have the permissions to run the script (`chmod +x`) and a stable internet connection while running the one-click script.
* Keep your RPC credentials and wallet secure, and ensure you have enough testnet ETH from the faucet to operate the node.
